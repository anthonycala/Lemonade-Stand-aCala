# Lemonade Stand → Sliminade Kiosk

This repository started as a C# console lemonade-stand simulation (`Lemonade_Stand/`). The active product is **Nayeli's Sliminade Stand Kiosk** — a web app for recording real stand sales and tracking inventory plus hard costs.

## Quick start

```bash
cd sliminade-kiosk
npm install
npm run dev
```

See [sliminade-kiosk/README.md](sliminade-kiosk/README.md) for kiosk usage.

**Live site (after Pages is enabled + merge to `master`):**  
https://anthonycala.github.io/Lemonade-Stand-aCala/

## Legacy

`Lemonade_Stand/` is the original .NET Framework 4.7.2 learning project and is not used by the kiosk.
